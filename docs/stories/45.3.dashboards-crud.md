## Story

Como time, quero **criar, listar, renomear, duplicar e apagar dashboards**, para ter mais de um recorte salvo sem depender de tela nova.

## Contexto Técnico

### O documento

```ts
{
  id, projectId, nome,
  widgets: Widget[],          // definição + geometria, NUNCA resultado
  dateRange: { preset: "last_30d" } | { start, end },
  criadoPor, criadoEm, atualizadoEm,
}
```

`widgets` é JSONB. O resultado de cada widget **não é persistido** — é recalculado. Persistir resultado cria a pior classe de bug: número velho com cara de atual.

### Endpoints

| Método | Rota | Nota |
|---|---|---|
| GET | `/api/projects/:projectId/bi/dashboards` | lista do projeto |
| POST | `.../dashboards` | cria vazio |
| GET | `.../dashboards/:id` | documento completo |
| PUT | `.../dashboards/:id` | **patch parcial**: `{nome}` ou `{dateRange}` ou `{widgets}` isolados |
| POST | `.../dashboards/:id/duplicate` | cópia com "(cópia)" no nome |
| DELETE | `.../dashboards/:id` | |

O `PUT` parcial não é detalhe: o canvas salva **só** `widgets` a cada arrasto, e mandar o documento inteiro faria dois salvamentos concorrentes se sobrescreverem.

## Critérios de aceitação

**AC1** — O `projectId` da rota é validado contra o acesso de quem chama. Guest não acessa nada aqui.

**AC2** — `PUT` aceita patch parcial e **não apaga** o que não veio no corpo.

**AC3** — Duplicar copia widgets e geometria, gera ids novos para os widgets, e não copia nada de resultado.

**AC4** — Apagar exige confirmação na UI e é irreversível no servidor (sem lixeira nesta story).

**AC5** — Limite de 60 widgets por dashboard, com mensagem clara ao exceder.

### O `PUT` parcial precisou de duas guardas, não uma

Aceitar patch parcial resolve o AC2, mas abre uma falha silenciosa: um corpo com
`widget` no lugar de `widgets` sairia como **200 sem salvar nada**. Por isso o
schema é `.strict()` — chave desconhecida é 400 — e corpo vazio também é 400, em
vez de um 200 que a tela mostraria como "salvo".

### Acesso: 404, nunca 403

Guest não entra no BI (o construtor lê o funil inteiro, não a fatia do
convidado), e projeto inexistente responde igual a projeto sem acesso. Confirmar
existência com 403 já é informação.

### O período viaja resolvido

O preset é salvo como **nome** (`last_30d`), nunca como par de datas: "últimos 30
dias" salvo em agosto precisa continuar significando os últimos 30 dias em
setembro. Mas a resposta traz também o período **já resolvido**, porque deixar o
cliente calcular faria o navegador em outro fuso chegar num dia diferente do
servidor. `hojeEmSaoPaulo()` usa `Intl` com o nome IANA — há teste com 01/09 às
02h UTC, que ainda é 31/08 aqui.

### Widget ilegível é contado, não descartado

Se a forma do widget mudar embaixo do dado salvo, o inválido some do canvas. A
leitura devolve `widgetsIlegiveis`, para a tela dizer "3 widgets antigos não
abrem" em vez de mostrar espaço vazio.
