## Story

Como time, quero **criar, listar, renomear, duplicar e apagar dashboards**, para ter mais de um recorte salvo sem depender de tela nova.

## Contexto Técnico

### O documento

```ts
{
  id, projectId, nome,
  widgets: Widget[],          // definição + geometria, NUNCA resultado
  dateRange: { preset: "last_30d" } | { start, end },
  criadoPor, criadoEm, atualizadoEm,
}
```

`widgets` é JSONB. O resultado de cada widget **não é persistido** — é recalculado. Persistir resultado cria a pior classe de bug: número velho com cara de atual.

### Endpoints

| Método | Rota | Nota |
|---|---|---|
| GET | `/api/projects/:projectId/bi/dashboards` | lista do projeto |
| POST | `.../dashboards` | cria vazio |
| GET | `.../dashboards/:id` | documento completo |
| PUT | `.../dashboards/:id` | **patch parcial**: `{nome}` ou `{dateRange}` ou `{widgets}` isolados |
| POST | `.../dashboards/:id/duplicate` | cópia com "(cópia)" no nome |
| DELETE | `.../dashboards/:id` | |

O `PUT` parcial não é detalhe: o canvas salva **só** `widgets` a cada arrasto, e mandar o documento inteiro faria dois salvamentos concorrentes se sobrescreverem.

## Critérios de aceitação

**AC1** — O `projectId` da rota é validado contra o acesso de quem chama. Guest não acessa nada aqui.

**AC2** — `PUT` aceita patch parcial e **não apaga** o que não veio no corpo.

**AC3** — Duplicar copia widgets e geometria, gera ids novos para os widgets, e não copia nada de resultado.

**AC4** — Apagar exige confirmação na UI e é irreversível no servidor (sem lixeira nesta story).

**AC5** — Limite de 60 widgets por dashboard, com mensagem clara ao exceder.
