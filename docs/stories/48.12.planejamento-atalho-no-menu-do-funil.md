## 💼 O pedido

Hoje o painel tem três entradas: o cartão no grid do funil (48.1), a seção no popover da engrenagem da página do funil (48.7 fatia A) e a seção dentro do dialog "Configurações do Funil" da barra lateral (48.7 fatia B). A última obriga dois cliques — abrir **Configurações**, depois **Abrir Planejamento**. O pedido é um item **direto** no menu de três pontos do funil na barra lateral, logo abaixo de "Configurações".

**Onde fica (conferido no código em 2026-09-23):** `packages/web/components/layout/project-folder.tsx:250-300` — `DropdownMenuContent` com, nesta ordem: Renomear funil · Configurações · Alterar para {Perpétuo|Lançamento} · Arquivar funil · Deletar funil. O menu inteiro só é renderizado quando `isAdmin` (`:240`).

## ✅ Acceptance Criteria

- **AC1** — No menu de três pontos do funil na **barra lateral**, um item **"Painel de Planejamento"** aparece **imediatamente abaixo de "Configurações"**. Ordem final: Renomear funil · Configurações · **Painel de Planejamento** · Alterar para … · Arquivar funil · Deletar funil.
- **AC2** — O item só aparece quando `temPainelDePlanejamento(funnel.type)` é verdadeiro (funil de **lançamento** — decisão E1 do epic; a mesma regra do cartão, do popover e do dialog). Em funil perpétuo ou mobile o item **não** aparece.
- **AC3** — Clicar navega direto para `planejamentoHref(projectId, funnel.id)` — a sub-página do **funil** — na mesma aba, sem abrir o dialog de Configurações. Usar o helper existente; nenhum caminho escrito à mão.
- **AC4** — As três entradas existentes (cartão, popover da página, seção do dialog da lateral) **continuam** como estão.
- **AC5** — Visibilidade herda a do menu: o menu de três pontos só existe para admin hoje (`isAdmin`, `project-folder.tsx:240`) — esta story não muda isso.
- **AC6** — Gates: eslint web 0; `next build` EXIT 0; `tsc` web 0 **depois** do build; vitest web verde.

## 🚫 Fora do escopo

- Mudar quem vê o menu de três pontos (hoje só admin).
- Remover ou mover as entradas existentes.
- Menu de três pontos da página do funil ou da etapa (o pedido é o da barra lateral).
