# 29.64 — NO-GO (6/10)

## F1 (bloqueante) — o AC1 manda fazer algo que a arquitetura não permite

**Onde:** AC1 — *"`srcDoCriativo` passa a consultar o `/creative-thumb` **antes**
de cair em `creativeImgSrc`"*.

Isso não é implementável como escrito:

```ts
// srcDoCriativo é SÍNCRONA e devolve string:
function srcDoCriativo(c, nome, doDrive): string {
  return doDrive(nome)?.url || creativeImgSrc(c);
}

// useCreativeThumb é um HOOK, por ad_id, com fetch autenticado:
export function useCreativeThumb(projectId: string, adId: string | ...) {
  const { getToken } = useAuth();
  return useQuery({ ... });   // devolve data URL, assíncrono
}
```

Não se chama hook dentro de função utilitária. E movê-lo para o componente
significaria **um hook por card** — condicional (viola as regras dos hooks) ou
100 queries autenticadas por render.

**O próprio PR #632 mostra o padrão certo, e a story não o seguiu:** o Drive
resolve com **um endpoint que devolve o mapa inteiro** (`useDriveCreatives` →
`Record<nome, DriveCriativo>`) e um lookup síncrono. Para o `/creative-thumb`
entrar na mesma cascata, seria preciso:

1. **um endpoint em lote** (`/creative-thumbs?adIds=…`) devolvendo N de uma vez — o
   caminho coerente com o #632; ou
2. **uma rota que sirva a imagem sem header**, para ir direto no `<img src>` — o
   que põe token em querystring e eu não recomendo.

**Consequência para a estimativa:** S (3) cobre "encaixar um degrau". Não cobre
criar endpoint em lote, e o AC5 já pressentia o problema (`um fetch autenticado
por anúncio… até 100 criativos`) sem nomear que ele **inviabiliza** o AC1.

**Correção:** o AC1 precisa dizer *o quê* (a cascata ganha o degrau) e deixar o
*como* para a implementação, com o endpoint em lote declarado como parte do
escopo — e a estimativa revista para M.

> Esta é a terceira vez que um AC deste epic nomeia a função a usar e acaba
> especificando um meio impossível. O padrão vale registrar: AC fixa resultado,
> não implementação.

## F2 (obrigatória) — medi com funis reais, e o resultado inverte a D1

O @sm testou 4 combinações, das quais **3 eram derivadas** (`PP-S1`, `FZ-L3` não
são funis reais) — e declarou esse limite, o que é correto. Refiz com os **14
funis reais que tiveram investimento nos últimos 30 dias**:

```
   BBE   bbe-fc1-mai-26 … bbe-web-mai-26   (11 casos)   parou em: Campanha
   DG    dg-a1, dg-pg02                    ( 3 casos)   parou em: MATERIAIS

   FUNIS REAIS COM ARQUIVOS NO DRIVE:  0 de 14
```

**Zero.** O preview do Drive não está entregando nada em produção hoje — a
cascata do #632 cai 100% na Meta.

Isso confirma a priorização Alta, mas **inverte a leitura da D1**: se o Drive não
entrega nada, acrescentar um degrau de 400px é consolo, não solução. Consertar o
que impede o Drive de resolver devolveria o **arquivo original** para todos os
projetos, e é onde está o ganho real.

Note o padrão: o BBE nem acha a pasta da campanha; o DG acha e para em
MATERIAIS. Estruturas diferentes entre drives apontam mais para **convenção /
uso operacional** do que para bug de código — mas é exatamente o que o AC0
precisa separar.

**Correção:** substituir a medição do @sm por esta (14 funis reais), e reescrever
a D1 declarando que o AC0 pode **redirecionar o esforço inteiro** para a correção
do resolvedor, com esta story virando follow-up.

## O que está muito bem feito

público** (`/creatives`) e atualizar o `llms.txt`.

## O que está muito bem feito

- **O achado central não é a URL, é o rótulo.** "Trocar para o `creativePermalink`
  está correto?" poderia ter virado uma story de trocar quatro `href`. A story
  identifica que os três botões têm `Assistir no Facebook` **fixo no código** e
  que ~4% dos anúncios caem mesmo no Facebook — logo, qualquer texto fixo estará
  errado numa ponta. Isso é achar o defeito atrás do pedido.
- **O bloqueio técnico está mapeado antes:** a rota `/creative-video` só devolve
  `adPermalinkUrl`, então hoje esses quatro pontos **não têm de onde tirar** a
  cascata. Sem o AC1, os outros ACs seriam impossíveis — e a story sabe disso.
- **O AC4 protege o contrato de máquina.** `adPermalinkUrl` permanece, o campo
  novo é aditivo, e o `llms.txt` entra no escopo. Feed público quebrado é o tipo
  de dano que só aparece semanas depois.
- **O AC7 pede o teste que quebra nas DUAS direções** (link do IG não pode dizer
  "Facebook"; link do FB não pode dizer "Instagram"). Um teste de "o botão
  aparece" passaria com o bug de volta.
- **O AC3 exige a derivação em módulo próprio** — e a story explica que é isso
  que torna o AC7 possível, dado que o runner do web não cobre componentes.
