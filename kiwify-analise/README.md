# Exports da Kiwify — apoio de análise

Pasta para os CSV/XLSX baixados direto da Kiwify, usados **só para análise**.
Nada aqui é lido pelo sistema em runtime.

⚠️ **Estes arquivos contêm dados pessoais** — nome, e-mail, telefone e valores de
compra de clientes reais. A pasta está no `.gitignore` e precisa continuar assim.
Nenhum arquivo daqui pode ser commitado, colado em issue, ou enviado para fora.

Ao terminar a análise, apague os arquivos. O que fica é a conclusão, não o dado.
